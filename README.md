三種語言：繁體中文、简体中文、English。

## 這個 repo 只放產物，不要手改

HTML 由 `kyappstudio/LiveLED`（私有）的 `docs/PRIVACY.md`、`docs/TERMS.md` 產生：

```bash
python site/gen.py    # 在 LiveLED 專案內執行
```

要修改政策內容，請改私有 repo 的 Markdown 原始檔再重新產生並推上來。
**直接編輯這裡的 HTML 會在下次產生時被蓋掉，而且會讓政策內容與原始檔不一致。**
